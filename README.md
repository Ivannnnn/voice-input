# Cloud Voice Input V1

Adds a voice-mode Android IME so HeliBoard can discover Cloud Voice Input.

After installing:
1. Open Cloud Voice Input.
2. Tap Open input method settings.
3. Enable Cloud Voice Input and keep HeliBoard enabled.
4. Open any text field.
5. Open HeliBoard.
6. Tap its microphone.
7. Cloud Voice Input should replace the keyboard area.
8. Tap Insert test transcription.

Expected text:
Hello from Cloud Voice Input. The HeliBoard voice IME works.
